# 上善若水：AI 时代的柔性领导力

职场提升俱乐部 Career Up Club · 柔性领导力系列课程课件。

- `Lead-Like-Water_柔性领导力课件.pptx` — 55 页，每页的讲稿在 PowerPoint 的“备注”栏。
  - 第 1–43 页：主讲部分（约 70 分钟）——开场、变局、柔性领导力 GIA、ACE、你的价值、行动与邀请。
  - 第 44–54 页：Q&A（约 30 分钟），每个问题一页。
- `build_deck.js`、`art.js` — 生成课件的脚本（文字、讲稿、配图都在里面）。

页面上带方括号的内容（如 `[主讲人]`、`[待确认]`）是需要替换的占位。

## 重新生成

```bash
npm install pptxgenjs sharp react react-dom react-icons
node build_deck.js
```
